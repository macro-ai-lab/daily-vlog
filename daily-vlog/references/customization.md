# 말로 요청하는 커스터마이징

제목, 시간 고정, 글꼴, 크기·색·위치 수정 요청이 있으면 읽는다. 에이전트가 사용자 말을 편집 계획의 `text_overlays`로 옮긴다. 사용자에게 JSON이나 명령 작성을 요구하지 않는다. 아래 예시는 기능 설명이며 모든 영상에 강제하는 기본값이 아니다.

현재 영상의 수정과 함께 재사용 가능한 선호는 [개인 지침 오버라이드](user-overrides.md)의 전·후 패치로 자동 제안한다. 영상 수정 승인과 영구 저장 승인은 별개이며, 사용자가 이번만 원하면 저장 제안 없이 해당 영상에만 적용한다.

## 요청을 설정으로 연결하기

| 사용자 요청 | 처리 |
|---|---|
| 제목을 위에 달아줘 | `title.text`, `position:top`, `position_mode:fixed`. 제목 문구가 없으면 이미 정한 작품 제목을 쓰고 알린다. 작품 제목도 없으면 문구만 질문한다. |
| 제목은 첫 장면에만 | 전역 title은 `enabled:false`, 첫 컷의 title만 `enabled:true` |
| 시간은 항상 가운데 고정 | time에 `position:center`, `position_mode:fixed`. 컷별 이동값과 분리해 화면 중심에 고정한다. |
| 시간만 고정하고 문장은 아래로 | time 고정을 유지하고 caption에 별도의 position 또는 x/y 적용 |
| 얼굴에 겹치면 옮겨줘 | 해당 요소만 `position_mode:follow_shot`, 컷별 위치를 저장한다. 고정 요청과 충돌하면 임의로 고정을 해제하지 않는다. 다른 컷·구도를 검토하고 해결이 안 되는 경우에만 사용자에게 대안을 고르게 한다. |
| 폰트는 구글 고딕으로 | **Noto Sans KR로 해석했다고 알린다.** Google Sans 등 다른 글꼴을 구체적으로 지목했다면 대체하지 말고 정확한 파일과 사용 가능 여부를 확인한다. |
| 시간만 크게·제목만 노란색 | 해당 요소의 font_size 또는 color만 변경한다. |
| 이 스타일을 다음에도 기본으로 | 요청 범위를 기록하고 스타일만 담은 프리셋을 저장한다. 시간 값·제목 문구·개인 영상 경로를 전역 기본값으로 저장하지 않는다. |

이미지 콘티 검토 중에는 수정 계획으로 `storyboard`를 다시 실행해 컷 번호가 붙은 이미지를 갱신한다. 사용자가 영상 제작까지 요청하기 전에는 자동으로 MP4로 넘어가지 않는다.

단순 수정 요청 자체가 해당 수정의 승인이다. 승인된 콘티·스타일을 반복 질문하지 말고 대표 스틸을 점검한 후 새 버전으로 렌더한다. 새 폰트 다운로드가 필요하면 알려주고 필요한 실제 실행 권한만 받는다. 지원하지 않는 효과·복잡한 애니메이션은 가능하다고 약속하지 않는다.

## 계획과 수정 패치

계획 최상위 `text_overlays`와 각 shot의 `text_overlays`가 같은 요소별 설정을 지원한다. 기본 스타일 → 전역 요소 설정 → 컷별 요소 설정 순으로 합친다. 전역 `position_mode:fixed`의 위치를 바꾸는 컷별 설정은 오류로 거부한다. 이때 고정한 요소를 움직이는 대신 오래된 컷별 위치 설정만 제거한다. `timeline_offset_y`는 `follow_shot` 요소에만 적용하고 제목은 기본적으로 고정한다. 기존 `text_overlays`가 없는 계획은 이전 렌더 결과를 유지한다.

```json
{
  "text_overlays": {
    "title": {
      "text": "10월의 작은 순간들",
      "position": "top",
      "position_mode": "fixed",
      "font_size": 64
    },
    "time": {
      "position": "center",
      "position_mode": "fixed",
      "font_size": 54
    },
    "caption": {
      "position": "bottom",
      "position_mode": "fixed",
      "font_size": 52
    }
  }
}
```

각 요소는 `enabled`, `font`(로컬 경로), `font_index`, `font_weight`(가변 폰트만), `font_size`(24~140), `color`, `stroke_color`(`#RRGGBB`), `stroke_width`(0~6), `shadow_opacity`(0~255), `align`(left/center/right)을 지원한다. 제목·문장에는 `text`도 쓸 수 있다. `time.text`는 금지하며 촬영 근거가 붙은 shot의 `time_label`만 표시한다. 실제 시각을 모르는 컷에 시각을 생성하지 않는다. 스톡·연출 시각의 출처 표시도 제목으로 숨길 수 없다.

시간만 중앙에 고정해 기존 문장과 겹치면, 위치를 명시하지 않은 문장만 시간 아래로 배치한다. 문장 위치까지 명시한 경우에는 임의 이동하지 않고 스틸에서 충돌을 확인해 해당 요소의 조정안을 만든다.

`position`은 top/center/bottom으로, 글씨의 보이는 중심을 각각 y=160/960/1700에 놓는다. x는 기본 540. position과 함께 지정한 x/y도 글씨 중심 좌표다. position 없이 지정한 y는 기존 계획과 같은 글씨 윗변 좌표다. x는 align에 따라 왼쪽/중앙/오른쪽 기준이다. 화면은 1080×1920 기준이며 제목·시간·문장은 각각 한 줄이다. 안전 영역을 벗어나면 임의 축소·잘라내기 없이 오류를 보고 짧은 문구나 조정안을 만든다. 그림자·테두리도 확인한다.

에이전트가 위 패치를 작업 폴더에 저장하고 실행한다:

```sh
bash scripts/run.sh customize plan-v001.json --root WORKDIR --patch style-patch-v002.json --output plan-v002.json
```

컷별 패치는 `"shots":{"1":{"text_overlays":{"title":{"enabled":true}}}}`처럼 **1부터 시작하는 문자열 번호**를 사용한다. 도구는 원본 계획을 보존하며 스타일만 수정한다. 장면 순서·원본·시간 근거·음원은 이 명령으로 바꾸지 않는다. 수정한 계획으로 기존 render 명령을 실행한다.

패치에서 설정값을 `null`로 쓰면 그 설정만 제거한다. 예를 들어 가변 폰트에서 정적 폰트로 바꿀 때 `font_weight:null`, 시간 고정과 충돌하는 과거 컷별 위치를 지울 때 해당 컷에 `y:null`을 쓴다. 최종 계획에는 null을 남기지 않는다.

## 폰트 파일 확보

배포 기본값은 번들 `assets/fonts/NotoSansKR-Regular.otf`이며 추가 다운로드 없이 재사용한다. Pretendard 번들은 기존 계획·명시적 선택에만 사용한다. Noto Sans KR의 다른 굵기가 필요할 때에만 공식 Google Fonts 가변 폰트와 OFL을 내려받는다:

```sh
bash scripts/run.sh font --name "Noto Sans KR" --output-dir WORKDIR/fonts/noto-sans-kr
```

반환된 절대경로를 원하는 각 요소의 `font`에 넣고, 가변 글꼴에는 `font_weight:600`(또는 요청한 굵기)을 넣는다. 전역 font만 바꾸면 요소에 명시한 폰트가 우선할 수 있으므로 실제 적용된 요소도 갱신한다. 파일·라이선스·출처 URL·해시를 작업 폴더에 보존하고 시스템 폰트를 설치하거나 현재 글꼴을 조용히 대체하지 않는다. Pretendard·SUIT·마루 부리·고운바탕·검은고딕은 [용도별 글꼴](typography.md)의 같은 `font` 명령으로 번들 경로를 반환한다. 정적 폰트로 바꿀 때는 이전 font_weight를 제거한다. 그 밖의 폰트는 확인된 로컬 파일 또는 공식 배포 경로를 이용하며 이름만 기록하고 적용됐다고 말하지 않는다.

## 적용 범위와 재개

영상 수정은 현재 프로젝트의 새 계획에 적용한다. 재사용 가능한 선호는 개인 오버라이드 후보로 제안하고, 저장 승인을 받으면 프로젝트 밖의 개인 프로필에 기록해 다음 대화·프로젝트에도 자동으로 읽는다. `WORKDIR/style-preset.json`은 프로젝트 프리셋으로 쓸 수 있지만 영구 개인 지침의 저장소를 대신하지 않는다. 후보·승인·거절 상태는 `vlog-session.json.customization`에 기록한다.

재개 시 최신 계획과 프리셋을 먼저 확인한다. 기본값보다 사용자 설정을 우선하고, 과거 자동 얼굴 회피 값으로 고정 위치를 덮어쓰지 않는다. 위치·글꼴·크기를 적용한 대표 스틸과 렌더된 컷 경계를 점검하고, 고정 위치와 얼굴 회피를 동시에 만족하지 못한 부분은 검수 보고에 구체적으로 적는다.
