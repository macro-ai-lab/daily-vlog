# 실제 프레임 이미지 콘티

글 콘티 피드백을 반영한 뒤, 영상 렌더 전에 읽는다. 사용자는 컷 번호를 보며 글꼴·자막·제목·시간 위치를 말로 고친다. 생성형 이미지로 원본 인물이나 글자를 다시 그리지 않는다.

## 만들고 보여주기

글 콘티의 구간·문구와 사용자가 이미 정한 스타일을 [편집 계획](plan.md)에 담는다. 스타일이 비어 있으면 [용도별 글꼴과 배치](typography.md)의 추천안을 우선 이미지로 제안한다. 아직 스타일 승인이 없는 계획으로 **스틸을 만드는 것은 가능**하지만 MP4를 렌더하지 않는다.

```sh
bash scripts/run.sh storyboard plan-v001.json --root WORKDIR --output-dir outputs/storyboard-v001
```

Windows에서는 같은 인자를 `scripts\run.cmd storyboard ...`로 실행한다. 에이전트가 명령과 계획을 다룬다. 출력 폴더는 새 이름을 사용한다.

- `shot-01.png` 등: 각 컷의 실제 1080×1920 스틸. 해당 구간 중간 프레임에 최종 MP4와 같은 크롭·시간·제목·자막을 합성한다. 움직이는 가로 크롭도 해당 프레임 시점에 맞춰 적용한다.
- `shot-01-guide.png` 등: UI 회피 참고 영역과 중앙선을 넣은 배치 검토용. 표시 영역은 공식 Instagram 안전 영역 규격이 아니며 사용자 고정 위치를 자동 변경하지 않는다.
- `storyboard-01.png` 등: 컷 번호·길이·원본 시점이 붙은 최대 6컷 단위 전체 콘티. 개별 화면 폭은 360px이므로 작은 화면의 글자 크기도 함께 볼 수 있다.
- `storyboard-01-guide.png` 등: 같은 전체 콘티의 안내선 버전. 안내선은 MP4에 들어가지 않는다.
- `storyboard.json`: 계획 원본·유효 설정 해시, 폰트 해시, 컷과 원본 프레임 연결, 생성 이미지 목록. `agent_image_view:not_checked`와 `motion_review:not_checked`는 자동 생성 사실만 뜻한다.

에이전트가 실제로 전체 콘티와 필요한 개별 이미지를 연 뒤 사용자에게 보여준다. 명령 성공·파일 생성만으로 이미지 열람이나 사용자 승인을 완료했다고 하지 않는다. 한 장면만으로 이동 중 얼굴·손 가림을 보장할 수 없으므로 최종 영상에서도 확인한다.

## 피드백과 버전

“2번 설명을 위로”, “시간은 가운데 고정”, “첫 컷 제목만 크게”를 [customize](customization.md)의 전역/컷별 패치로 바꾼다. 원본 계획은 유지한 새 계획으로 이미지 콘티를 다시 만든다. 시간 값·원본·촬영 근거를 스타일 패치로 바꾸지 않는다.

사용자가 고정한 요소는 얼굴 회피를 이유로 이동하지 않는다. 설명·크롭·구간을 조정한다. 해당 수정 요청 자체는 수정 실행의 승인이다. 새 이미지에서 선택을 확인하되 똑같은 콘티·스타일 승인을 재질문하지 않는다. “이대로 영상으로 만들어줘”는 보여준 콘티와 스타일에 대한 승인으로 기록할 수 있다.

`vlog-session.json.visual_storyboard`에 버전·manifest·계획 해시·실제 열람 결과를 기록하고 `style.approval`에 사용자 답과 선택 버전을 연결한다. 계획·문구·폰트·개인 오버라이드가 바뀌면 이전 이미지 승인을 새 설정의 승인으로 확대하지 말고 영향을 받은 이미지를 갱신한다. `storyboard.json`의 원래 점검 상태를 덮어쓰지 말고 에이전트 검수는 세션에 별도로 남긴다.

## 효과와 검토 범위

현재 지원하는 디자인 수정은 실제 폰트·크기·색·위치·고정·테두리·그림자다. 제목·시간·설명은 각각 한 줄이다. 두 줄 설명, 반투명 박스, 단어별 색, 팝업·타이핑·페이드·전환 애니메이션은 아직 지원하지 않는다. 작동하지 않는 효과를 이미지에만 그려 최종 영상에서도 구현된 것처럼 보여주지 않는다. 새 움직임을 구현한 경우 정지 콘티는 배치 확인에 쓰고 짧은 동작 샘플을 추가 확인한다.
