# 이미지 생성으로 그리는 콘티

글 콘티 피드백을 반영한 뒤 읽는다. **기본 이미지 콘티는 이미지 생성 도구로 그린 장면별 콘티**다. 실제 영상 프레임을 추출·합성한 시트로 대체하지 않는다. 촬영·피드 콘티처럼 장면 그림, 컷 번호, 자막 자리, 효과 메모를 한눈에 보여준다.

## 생성과 피드백

1. 글 콘티의 피드백을 반영해 장면 순서·행동·짧은 문구를 정리한다. 이 단계에 최종 렌더용 JSON이나 실제 영상 스틸은 필요하지 않다. 원본 분석에서 확인한 내용을 바탕으로 그리되 영상에 없는 사건·관계·촬영 시각을 사실처럼 추가하지 않는다.
2. 현재 세션의 이미지 생성 도구를 사용한다. 장면별 그림과 컷 번호가 있는 다중 패널 콘티를 만든다. 컷 수에 따라 보통 한 장에 4~6컷, 필요하면 여러 장 또는 9컷 구성을 사용한다. 각 패널 안의 영상 영역은 세로 구도로 보여주고, 설명·효과 메모는 영역 밖에 둔다. 사용자가 이전에 고른 촬영·피드 콘티가 있으면 같은 구성과 그림 분위기를 따른다.
3. 제목·시간·설명의 상대 위치, 크기 차이, 색과 강조 지점을 그림에 넣는다. “시간은 가운데 고정” 같은 요청은 모든 패널에서 유지한다. 촬영 시각을 모르면 `촬영시각` 같은 자리표시자를 쓰거나 생략한다. 패널 그림 자체가 재구성 예시임을 짧게 알리고 실제 원본 프레임이라고 표현하지 않는다.
4. 생성 이미지를 실제로 확인해 컷 누락·번호·한글·자막 위치를 점검하고 보여준다. 생성 이미지의 글자가 틀리면 이미지 도구로 고치거나 옆의 정확한 문구를 함께 제공한다. 파일 생성 성공만으로 사용자 승인을 완료하지 않는다.
5. “2번 자막 위로”, “3번만 포인트”, “시간은 계속 가운데” 같은 피드백을 해당 컷과 생성 프롬프트에 반영한다. 기존 콘티를 편집할 때는 이전 이미지를 편집 대상으로 넣고 나머지 컷·구도·문구를 유지하도록 명시한다. 새 버전으로 저장한다.
6. 사용자가 이미지 콘티를 확인하면 구도·자막·스타일 의도를 [편집 계획](plan.md)에 옮겨 영상 시안을 만든다. 같은 콘티·스타일 승인을 따로 반복하지 않는다. “이대로 영상으로 만들어줘”는 보여준 안의 승인으로 기록할 수 있다.

사용자 원본 사진·영상 프레임을 이미지 생성의 입력으로 붙일 필요는 없다. 특정 인물의 외모를 재현하라는 요청이 없다면 인물을 일반적인 그림으로 표현한다. 생성 콘티를 위해 원본을 별도 외부 서비스에 업로드하거나 외부 사이트 가입을 요구하지 않는다.

## 생성 프롬프트 구성

예시 문구를 실제 영상 내용으로 그대로 사용하지 말고, 확인한 글 콘티로 채운다.

```text
용도: 브이로그 편집용 그림 콘티. 실제 영상 캡처나 최종 영상이 아닌 연출 시안.
구성: [컷 수]개 패널, 읽는 순서대로 번호. 패널 안은 세로 영상 구도.
그림: [사용자가 고른 분위기 또는 일관된 스케치/일러스트]. 같은 인물·소품의 일관성 유지.
컷별 내용: [번호 / 확인한 행동 / 구도 / 자막 정확한 문구 / 제목·시간 자리 / 효과 메모].
글자: 제목·시간·설명의 역할과 상대 크기를 구분. 메모는 영상 영역 밖.
유지할 지침: [중앙 시간 고정 등 이번 요청과 승인된 개인 지침].
확인할 변경: [이번 피드백]. 다른 컷·문구·순서는 유지.
```

## 정확한 폰트와 효과

그림 콘티에서는 폰트 계열·굵기·분위기와 위치를 논의한다. 이미지 생성 결과가 특정 폰트 파일의 정확한 모양·픽셀 좌표·크기를 재현했다고 말하지 않는다. 선택한 폰트 이름과 설정은 별도로 기록하고, 실제 글꼴 파일을 적용한 영상 시안에서 확인한다. 필요하거나 사용자가 요청할 때만 [실제 프레임 스타일 미리보기](style-preview.md)를 추가한다. 이 선택 검사를 기본 그림 콘티로 대체하지 않는다.

효과 메모는 연출 의도를 표현할 수 있지만 지원 여부를 구분한다. 현재 폰트·크기·색·위치·고정·테두리·그림자는 편집기에 반영할 수 있다. 자막 애니메이션·두 줄 설명·반투명 박스·전환 등 미지원 기능을 구현 완료로 표시하지 않는다. 움직임은 정지 콘티의 화살표나 메모로 설명하고, 실제 지원·구현한 동작은 영상에서 확인한다.

## 도구 가용성과 재개

이미지 생성은 현재 에이전트 세션에 제공된 기능을 사용한다. 이 스킬의 로컬 설치기가 이미지 생성 서비스를 추가하는 것은 아니다. 기능이 없으면 그 사실을 짧게 알리고 생성용 프롬프트와 글 콘티를 보존한다. 실제 프레임 시트·ASCII·도식으로 몰래 대체하거나 이미지 생성을 마쳤다고 하지 않는다. API 키·유료 외부 서비스 연결은 사용자 요청 없이 추가하지 않는다.

`vlog-session.json.visual_storyboard`에 `kind:generated_illustration`, 버전, 이미지 경로, 프롬프트 경로, 컷 번호별 수정, 실제 열람 결과, 사용자 확인 근거를 기록한다. 최종 편집 계획이 아직 없어도 된다. 원본 파일 경로 같은 불필요한 개인정보를 생성 프롬프트에 넣지 않는다. 장면이나 배치가 바뀌면 이미지 버전도 갱신하되 이전 이미지·글 콘티는 보존한다.
