# 장면 분석에서 이야기 자막으로

[형식 선택](formats.md)에서 이야기형을 골랐을 때 장면 분석 후, 자막 초안과 그림 콘티 전에 읽는다. 일상 모음은 가벼운 주제·관찰만 활용하고 전체 이야기 구조를 강요하지 않는다. 타임로그는 이 이야기 설계 대신 촬영 순서와 행동 중심으로 구성한다. 분석은 무엇이 찍혔는지 확인하는 근거다. 그다음 사용자가 이 장면들을 왜 묶어 보여주려는지 한 줄 관점을 정하고, 그 관점으로 장면·문장을 연결한다. 명사형 행동 라벨을 여러 개 붙인 것을 내러티브라고 설명하지 않는다. 타임로그·무자막·담백한 관찰을 명시한 요청에는 이야기를 강요하지 않는다.

## 맥락과 관점

[진행 방식](workflow.md)의 분석 후 맥락 입력을 먼저 마친다. 장면 요약을 바탕으로 사용자가 설명한 **어떤 상황인지 / 무엇을 보여주고 싶은지 / 어떻게 표현하고 싶은지**를 이야기의 근거로 쓴다. 촬영 계기·에피소드·남길 감정·대상 시청자·꼭 살릴 장면이 있으면 활용한다. 영상 분석이 그 설명을 대체하지 않는다.

이미 말한 내용을 다시 묻지 않고 빠진 핵심만 한 번에 받는다. 질문했다면 답을 기다리고, 사용자 맥락을 받기 전에 AI가 관점·자막·콘티를 확정하지 않는다. 사용자가 내용 구성까지 맡겼다면 실제 장면으로 가능한 관점 하나를 추천해 콘티에 보여준다. 형식만 추천해달라는 답은 내용 전체의 위임이 아니다. ‘특별한 의미 없이 기록’이라는 짧은 답도 충분한 방향이다.

사용자가 준 방향을 단순한 분위기 이름에서 실제 이야기 관점으로 구체화한다. 시점·말투·원하는 마무리를 함께 적용하고, 부모의 속마음이나 아이의 실제 대사를 임의로 확정하지 않는다. 사용자 맥락과 충돌하는 핵심만 짧게 확인하며 별도 대본 승인 단계를 기본으로 추가하지 않는다.

하나의 큰 사건이 없는 일상에도 반복하는 소품, 달라지는 역할, 비슷한 행동, 작은 기대와 결과, 처음과 마지막의 대비를 찾을 수 있다. 가벼운 놀이 비유·유머·여운도 가능하다. 차분한 기록에는 관찰과 반복만으로 연결하고, 모든 영상에 갈등·반전·교훈·과장된 도입을 억지로 넣지 않는다.

## 이야기 한 줄 → 장면 역할 → 문장

1. **이야기 한 줄:** 보고 나서 남길 인상이나 작은 발견을 정한다. 예를 들어 역할놀이 영상 묶음이라면 ‘이것저것 해보는 아이를 바쁜 직장인처럼 바라보는 놀이 비유’가 될 수 있다. 예시의 비유·인물·소재를 모든 작품의 기본값으로 저장하지 않는다.
2. **시청 흐름:** 시작이 어떤 기대·궁금증·상황을 열고, 중간의 장면이 무엇을 보태거나 바꾸며, 마지막이 무엇을 회수하는지 정한다. 도입·확장·전환·반응·마무리는 장면의 기능이며 고정된 컷 수나 필수 5단계가 아니다. 같은 소품으로 시작과 끝을 잇거나, 행동의 결과를 마지막에 보여주는 정도로도 충분하다.
3. **장면 선택:** 이야기를 뒷받침하는 실제 구간을 사용한다. 모든 원본을 한 컷씩 의무적으로 쓰지 않으며 반복 장면은 덜어낼 수 있다. 원본이 부족하면 소박한 기록으로 범위를 좁힌다. 사용자 최대 길이·원본 길이·타임로그의 촬영 순서를 지킨다.
4. **자막 문장:** 장면마다 역할을 수행하는 짧은 문장을 쓴다. 앞 문장의 기대를 다음 문장이 받게 하고, 화면에 이미 보이는 것에 맥락·관찰·반응을 보탠다. ‘공원 산책 / 소방관 놀이 / 차 타기’ 같은 목록에 연결어만 붙이지 않는다. 의미를 읽을 시간이 부족하면 문장을 줄이거나 사건을 나눈다. 원음·표정으로 전달되는 구간은 자막을 비워도 된다.
5. **시각 연출:** 이야기 문장을 먼저 정한 뒤 [기본 편집](default-editing.md)의 흰색 본문·노란 반응·분홍 제목/마무리로 표현한다. 글로우·팝·전환이 이야기 기능을 대신하지 않게 한다.

## 창작 표현과 사실

분석 기록에는 확인한 행동과 촬영시각을 남기고, 편집안에는 해석·비유를 구분한다. 역할놀이의 ‘꼬마 기사님 출근 중’처럼 비유임을 알 수 있는 표현은 제안할 수 있다. ‘처음 운전한 날’, ‘겁이 나서 울었다’, ‘매일 인형을 데리고 잔다’는 첫 경험·원인·빈도·속마음을 추가하므로 영상이나 사용자 설명으로 확인해야 한다. 확인하지 않은 말을 직접 대사·녹취처럼 따옴표로 꾸미지 않는다.

여러 날짜의 클립은 ‘요즘의 기록’, ‘작은 순간 모음’ 같은 범위로 묶을 수 있다. 같은 하루·연속 사건·인과관계인 것처럼 문장으로 이어 붙이지 않는다. 역할이 바뀌는 비유와 실제 직업·사건을 혼동하지 않는다. 타임로그는 촬영 순서를 유지하고, 다른 형식에서 재배열하더라도 실제 시간 표시는 보존한다.

## 사용자에게 보여주기와 재개

그림 콘티 위에 이야기 한 줄과 시점을 짧게 적고, 각 패널 밖에 ‘상황 소개’, ‘기대 확장’, ‘반응’, ‘도입 회수’ 같은 해당 컷의 기능을 표시한다. 패널 안에는 정확한 자막 문구와 위치·스타일을 넣는다. 사용자는 장면·글자뿐 아니라 이야기 방향·말투·결말을 같은 콘티에서 바꿀 수 있다. 별도 글 대본 승인을 기본 단계로 추가하지 않는다.

에이전트가 `vlog-session.json.narrative` 또는 별도 작업 기록에 다음 내용을 보존한다. 최종 렌더러가 이 필드를 자동 해석한다고 설명하지 않는다.

- 사용자 맥락과 확인한 근거 / 미확인 사항
- 이야기 한 줄과 추천한 시점·말투
- 선택한 장면별 역할과 자막 문장
- 시작과 끝을 잇는 장치, 실제 날짜 범위
- 현재 콘티 버전과 사용자 피드백·확인 근거

자막만 순서대로 읽어도 한 관점으로 이어지는지, 마지막이 앞의 기대나 반복을 받는지, 장면마다 같은 설명을 되풀이하지 않는지 확인한다. 영상과 자막을 함께 봤을 때 실제 행동·원음과 어긋나는 문장을 고친다. 이야기 방향이 바뀌면 관련 자막·제목·콘티를 함께 갱신한다. 이미 승인한 색·폰트·시간 설정을 불필요하게 재질문하지 않는다.
