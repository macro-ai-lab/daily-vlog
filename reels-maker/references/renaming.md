# daily-vlog에서 릴스 메이커로

제품 이름과 스킬 폴더·호출 이름은 `reels-maker`(릴스 메이커)다. 기존 GitHub 저장소를 `macro-ai-lab/reels-maker`로 변경하며, 새 설치는 Codex `$reels-maker`, 로컬 Claude Code `/reels-maker`를 사용한다.

기존 사용자 설치의 파일·수정본·개인 지침을 자동으로 삭제하거나 덮어쓰지 않는다. 이름이 바뀌었다고 기존 작업을 새로 생성하지 않는다. 기존 설치를 전환하려는 요청을 받으면 설치 범위와 파일을 먼저 확인하고 백업·차이를 확인한 뒤 전환한다. 별도 설치 요청이 없는 개발·배포 변경만으로 사용자 설치를 교체하지 않는다.

호환성을 위해 개인 지침 경로 `daily-vlog/user-overrides.json`, `DAILY_VLOG_PROFILE`, `DAILY_VLOG_RUNTIME`, 기존 프로젝트/사용자 런타임 캐시와 `vlog-session.json`은 유지한다. 이름만으로 개인 지침을 새로 만들거나 다른 클라이언트의 지침을 가져오지 않는다. `reels-maker` 설치 기록은 `.reels-maker-install`이며 선택한 클라이언트·프로젝트/사용자 범위를 유지한다. 원래 `daily-vlog` 설치도 자신의 기록을 그대로 사용한다.

새 릴스 제작은 형식·선택적 레퍼런스 링크를 받고 타임로그일 때만 시간 표시를 질문한다. 이전 작품에 없는 필드를 채우려고 승인한 콘티·글꼴·자막 위치·원음 선택을 초기화하지 않는다.
