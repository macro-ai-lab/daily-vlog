# 참고 영상 링크

첫 영상 형식 질문에서 참고하고 싶은 영상이 있으면 링크도 함께 받는다. 링크는 선택 사항이다. 이미 링크·레퍼런스 파일·없다는 답을 받았으면 다시 묻지 않는다. 사용자가 형식만 답해도 링크를 요구하며 멈추지 않는다. 참고할 요소를 이미 설명했다면 재사용하고, 그렇지 않으면 접근 가능한 영상을 보고 구성·컷 리듬·자막 말투·배치 등 관측한 특징을 제안한다. 원하는 요소가 모호해 실제 선택에 영향을 줄 때만 한 번 짧게 확인한다.

## 확인과 분석

- 현재 세션에 있는 브라우저·컴퓨터 유즈로 접근 가능한 재생 화면을 확인한다. 이 문서는 새 브라우저 도구·영상 다운로드 프로그램을 설치하는 기능이 아니다. 사용자가 직접 첨부하거나 로컬 경로로 준 레퍼런스는 기존 frames/survey로 분석할 수 있다.
- 게시 제목·설명만 확인한 것, 실제 화면 일부를 본 것, 시간별 프레임을 확보한 것, 음성을 확인한 것을 구분한다. 일부 화면을 보고 전체 컷 지도·정확한 컷 길이·음악 청취까지 끝났다고 하지 않는다. 일반 간격 샘플만으로 모든 컷을 정확히 찾았다고 하지 않는다.
- 인스타 로그인·재생 제한·403 등으로 확인하지 못하면 inaccessible로 남기고 그 한계를 짧게 설명한다. 접근 가능한 레퍼런스 파일/화면이나 사용자 설명으로 진행할 수 있다. 사용자 허락 없이 로그인 쿠키를 읽거나, 스킬 설치만으로 인증 문제가 해결된다고 하지 않는다.
- 레퍼런스와 사용자 원본을 분리한다. 참고 영상의 장면·사람·대사·음악·촬영시각을 사용자의 사실로 가져오지 않는다. 레퍼런스 원본을 본편에 자동 삽입하거나 음악을 복사하지 않는다. 실제 원본에 가능한 구도·리듬·자막 톤을 콘티에 적용한다.

## 작품별 기록

세션의 `initial_options.references`에 `url`, `focus`, `access_status`, `evidence`를 기록한다. 링크만 받은 상태는 received, 일부 구간/화면만 봤으면 partially_viewed, 필요한 참고 범위를 확인했으면 reviewed, 접근할 수 없으면 inaccessible다. evidence에는 관측한 범위와 미확인 항목을 짧게 남기며 쿠키·토큰을 넣지 않는다. 없으면 빈 목록으로 진행한다. 링크가 끊겼다는 이유로 사용자가 이미 준 원본이나 확인한 설정을 버리거나 처음부터 다시 묻지 않는다.

콘티에는 적용할 참고 요소와 현재 원본에 맞게 바꾼 점을 표시한다. 레퍼런스의 접근 실패를 사용자 원본의 분석 실패로 처리하지 않는다. 사용자 설명만으로 진행했다면 설명에 근거한 것이라고 구분한다.
