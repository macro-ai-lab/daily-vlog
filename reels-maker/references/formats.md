# 먼저 고르는 영상 형식

새 작업에서 본격적인 장면 분석·자막 작성 전에 읽고 형식을 고른다. 아래 세 가지는 사용자가 결과를 예상하도록 나눈 편집 선택지이며 인스타그램의 공식 분류가 아니다. 타임로그에도 짧은 감상이 있을 수 있고 이야기형도 시간을 표시할 수 있다. 자막의 역할·장면 구성·내러티브의 비중으로 구분한다.

## 제한 없는 콘텐츠 유형과 편집 방식

타임로그·일상 모음·이야기형은 출발점인 편집 방식이며 전체 영상 종류의 닫힌 목록이 아니다. 쇼핑 후기·여행 후기·광고·사용법·비교 등 어떤 새 유형도 받을 수 있다. 시작 질문에 ‘다른 종류를 말해주셔도 돼요’라는 선택지를 포함한다. 이미 ‘쇼핑 후기 만들어줘’처럼 목적을 밝혔다면 그대로 받고 세 방식부터 다시 고르게 하지 않는다. 받은 목적·레퍼런스·원본에 맞는 구성을 제안하고 기존 분석·맥락·콘티 확인 흐름을 이어간다. 콘텐츠 유형과 편집 방식이라는 용어를 사용자에게 별도 설정 설문으로 강요하지 않는다.

에이전트는 세션과 편집 계획에 `content_type`(예: `shopping_review`), `content_type_label`(예: `쇼핑 후기`)을 기록하고 `edit_format`에는 실제 편집 방식(예: `story`, `comparison`, `demonstration`)을 따로 기록한다. 키는 소문자 영문으로 시작하는 영문·숫자·하이픈·밑줄 64자 이내다. 사용자에게 키를 입력시키지 않는다. 타입은 코드나 배포본 수정 없이 첫 실제 렌더 이력부터 자동 추가된다. 기존 `history show`의 유형 목록·표시명을 보고 같은 의미면 기존 키를 재사용하며 ‘구매 후기/쇼핑 후기’처럼 사소한 표현 차이로 유형을 무한 분리하지 않는다. 의미가 정말 다른 유형은 새 키로 추가한다. 구분이 중요한데 사용자 의도가 모호할 때만 짧게 확인한다.

예: 여행 후기를 시간순으로 만들면 `content_type:travel_review`, `edit_format:timelog`다. 광고를 비교 구성으로 만들면 `content_type:advertisement`, `edit_format:comparison`이다. 시간 질문은 편집 방식이 타임로그일 때만 적용하며, 쇼핑 후기나 광고라는 목적만으로 시간을 묻지 않는다. 여행 후기의 취향을 모든 시간순 영상에 확대하지 않는다. 기존 작품은 기존 타입 그대로 보존하고 임의 재분류하지 않는다.

## 사용자에게 보여줄 선택

> 어떤 형식으로 만들까요?
> 1. **타임로그** — 촬영 순서대로, 짧은 행동 자막 위주
> 2. **일상 모음** — 좋은 순간을 모아, 짧은 감상과 분위기 중심
> 3. **이야기형 릴스** — 한 가지 관점으로 시작·전개·마무리가 이어지게
> **쇼핑 후기·여행 후기·광고 등 다른 종류를 말해주셔도 돼요.**
> 잘 모르겠으면 **영상 보고 추천해줘**라고 해도 돼요.
> 참고하고 싶은 영상이 있으면 **링크도 함께 보내주세요. 없어도 괜찮아요.**

첫 형식 질문에서 선택적인 참고 영상 링크도 함께 받는다. 이미 형식을 골랐고 레퍼런스 여부만 미정이면 링크가 있는지만 짧게 묻는다. 형식 답변에 링크가 없더라도 선택 사항이므로 분석을 막거나 같은 링크 질문을 반복하지 않는다. 이미 받은 링크·첨부·없다는 답은 재사용한다. [레퍼런스 확인](reference-video.md)에서 보고 싶은 요소와 실제 접근 가능 범위를 구분한다. 그다음 컷당 최대 길이(기본 제안 2초)를 확인한다. **촬영시간 표시 여부 질문은 타임로그에서만 한다.** 일상 모음·이야기형은 미지정 시간 표시를 끄되 명시적 요청·기존 승인·개인 지침은 보존한다. 이번 요청·개인 지침·이미 승인한 작업에서 정해진 값은 다시 묻지 않는다. ‘브이로그 만들어줘’는 세 형식을 포괄하므로 이야기형을 선택했다고 가정하지 않는다. 시간 삽입 요청이나 폰트 취향만으로 형식을 확정하지 않는다.

‘타임로그로’, ‘일상 모음으로’, ‘경주 여행처럼 이야기가 이어지게’처럼 구체적으로 정했다면 해당 선택을 기록한다. ‘영상 보고 추천해줘’는 AI에 형식 추천·선택을 맡긴 답으로 기록하고, 길이를 정한 뒤 시간 표시 질문 없이 실제 장면을 분석하고 사용자 맥락을 받은 뒤 적합한 한 형식을 골라 이유를 그림 콘티에 표시한다. 최종 추천이 타임로그라면 콘티 생성 전에 미정인 시간 표시 여부만 확인한다. 최종 추천이 다른 형식이면 질문하지 않는다. 형식 추천을 맡긴 답만으로 상황·이야기 전체의 위임을 가정하지 않는다. 응답이 없다는 이유로 AI 추천이나 특정 형식을 선택했다고 처리하지 않는다. 한 작품 안에 형식을 섞어달라는 요청도 허용하며 중심 형식과 섞을 요소를 짧게 기록한다.

## 분석 후 사용자 맥락

모든 형식에서 [영상 분석 뒤 사용자 맥락 입력](workflow.md)을 거친다. 보이는 장면을 요약한 뒤 어떤 상황인지, 무엇을 보여주고 싶은지, 어떤 분위기·말투·방향을 원하는지 한 번의 편한 답변으로 받는다. 이미 준 맥락은 재사용하며 타임로그는 짧은 기록 범위 답으로도 충분하다. 답을 기다리는 동안 콘티를 먼저 만들지 않고, 내용 구성까지 맡겼을 때만 추천으로 진행한다.

## 형식별 편집 기준

| 항목 | 타임로그 | 일상 모음 | 이야기형 릴스 |
|---|---|---|---|
| 중심 | 언제 무엇을 했는지 | 어떤 순간과 분위기를 남길지 | 어떤 관점과 흐름으로 보여줄지 |
| 장면 연결 | 실제 촬영 순서 | 같은 분위기·행동·소품·하루/기간의 기록 | 관점 소개·확장·변화·반응·회수 등 필요한 기능 |
| 자막 | 짧은 행동·상황. 감상은 선택 | 짧은 관찰·감상·반응. 무자막 구간도 가능 | 앞뒤 문장이 이어지고 마지막이 앞의 기대나 모티프를 받음 |
| 이야기 설계 | 별도 줄거리·갈등·결말을 만들지 않음 | 느슨한 주제나 반복만으로 충분 | [이야기 지침](narrative.md)의 한 줄 관점과 장면 역할 설계 |
| 시각적 강조 | 담백한 글자, 일정한 자리. 팝·글로우는 요청이 있을 때 | 본문 중심, 필요할 때 작은 제목·포인트 | [기본 연출](default-editing.md)의 흰색 본문·노란 반응·분홍 제목/마무리 |
| 촬영시간 질문 | 이 형식에서만 묻고, 켰다면 실제 근거가 있는 시각만 | 묻지 않음. 미지정이면 끔 | 묻지 않음. 미지정이면 끔 |

새 타임로그·일상 모음의 담백한 시작값은 번들 Pretendard SemiBold 본문 60~70px, 시간은 표시를 선택한 경우 SUIT SemiBold 42px다. 사용자가 고른 다른 폰트·색·고정 위치가 우선한다. 이야기형의 강한 노란 기울임·분홍 글로우를 모든 형식에 자동 적용하지 않는다. 기존 Noto 중앙 타임로그 작품도 유지한다. 형식 선택은 영상 최대 길이·BGM·원음을 자동 결정하지 않는다. 비타임로그에서도 사용자가 시간 표시를 직접 요청하면 그 요청을 반영하되 해당 질문을 새로 만들지 않는다. 원음 유지는 모든 형식의 기본 정책이다.

같은 소방관 역할놀이 컷도 타임로그에서는 ‘소방관 놀이’, 일상 모음에서는 ‘헬멧 쓰니 제법 그럴듯’, 이야기형의 직장인 놀이 비유에서는 ‘소방관으로 출근했다가’처럼 기능이 달라질 수 있다. 문구는 예시이며 실제 사건·대사를 새로 단정하는 근거가 아니다.

## 콘티와 재개 기록

콘티 상단에 선택한 형식·추천 이유(추천을 맡긴 경우)·기간을 적는다. 타임로그 패널에는 시간 흐름과 행동, 일상 모음에는 장면과 짧은 관찰, 이야기형에는 이야기 한 줄과 컷별 기능을 표시한다. 형식에 맞지 않는 갈등·리액션·결말을 채우려고 새로운 사건이나 촬영시각을 만들지 않는다. 여러 날짜는 그 범위에 맞는 기록으로 다룬다.

`vlog-session.json.initial_options.edit_format`에 `timelog` / `moments` / `story`를 기록하고(AI 추천 위임 후 분석 전에는 `auto`), `format_choice_source`에 사용자 직접 선택·기존 확인·AI 추천 위임 중 근거를 남긴다. 미응답은 `null`이다. AI 추천을 맡긴 경우에는 위임 사실과 실제 선택 결과를 함께 보존한다. 이 필드는 에이전트의 작업 기록이며 렌더러의 새 자동 옵션이 아니다.

기존 세션에 형식 필드가 없으면 이미 승인한 콘티·편집 의도를 우선하고 형식 질문부터 재시작하지 않는다. 형식 전환을 요청하면 분석 자료·원본·확인한 길이와 시간 설정을 재사용하고, 달라진 자막·구성·스타일을 콘티에서 보여준다. 저장된 개인 지침보다 이번 작품의 선택이 우선한다.
