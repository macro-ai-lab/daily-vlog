# 일상 타임로그 · daily-vlog

아이폰 등으로 찍은 일상 영상을 Codex와 함께 짧은 세로 타임로그로 편집하는 스킬입니다.

[설치 ZIP 다운로드](https://github.com/macro-ai-lab/daily-vlog/releases/download/v008/daily-vlog-skill-v008.zip) · [v008 배포 안내](https://github.com/macro-ai-lab/daily-vlog/releases/tag/v008)

**영상 확인 → 콘티 확인 → 자막·스타일 선택 → 시안 제작 → 수정** 순서로 진행합니다. 설치 명령과 편집 계획은 Codex가 다루며, 사용자는 영상과 원하는 느낌을 말하면 됩니다.

## 가장 쉬운 설치

1. 파일을 읽고 명령을 실행할 수 있는 Mac 또는 Windows PC의 Codex를 엽니다.
2. 이 저장소 주소와 아래 문장을 함께 보냅니다.

> https://github.com/macro-ai-lab/daily-vlog
>
> 이 GitHub 저장소의 README와 daily-vlog/SKILL.md를 읽고, 내 운영체제에 맞게 일상 브이로그 스킬을 설치해줘. 필요한 편집 도구도 준비하고 실행 점검까지 해줘. 기존 스킬이 있으면 덮어쓰지 말고 버전을 확인해줘.

3. 필요한 폴더 접근·설치·네트워크 승인 요청이 나오면 내용을 확인합니다.
4. 준비되면 영상을 첨부하거나 **편집 컴퓨터에 있는** 영상 파일/폴더 위치를 알려줍니다.

> 이 영상들로 타임로그를 만들어줘. 컷당 약 2초로, 1초 영상은 그대로 쓰고 긴 영상은 핵심 동작만 골라줘. 먼저 콘티를 보여줘.

큰 영상은 채팅에 다시 올릴 필요 없이 편집 컴퓨터의 파일 경로로 전달할 수 있습니다. 원격 컴퓨터를 쓴다면 원본이 그 컴퓨터에서 읽히는 위치에 먼저 있어야 합니다. 이 버전에는 휴대폰 사진첩 연동이나 공유 링크 자동 다운로드가 없습니다.

## ZIP으로 설치하기

Releases에 배포 ZIP이 있다면 다운로드하여 완전히 압축을 푼 뒤, 그 폴더를 Codex에 알려 설치를 요청할 수 있습니다. 직접 실행하려면 Mac은 `install.command`, Windows는 `install-windows.cmd`를 사용합니다.

최초 실행 시 인터넷으로 **uv → 전용 Python 3.12 → 영상 모듈**을 준비합니다. Python, uv, Homebrew, Git을 사전에 설치할 필요가 없습니다. 공개 배포 ZIP 다운로드에는 GitHub 계정이 필요하지 않습니다. Codex 이용을 위한 설치·로그인과 서비스 요금은 별개입니다.

기존에 같은 이름의 스킬이 있으면 설치기는 임의로 덮어쓰지 않습니다. 자동 업데이트 기능은 아직 없으며, 새 배포본 적용 시 기존 설정과 버전을 확인해야 합니다.

## 현재 편집 기능

- 원본 길이에 관계없이 약 2초의 핵심 구간으로 구성하는 타임로그. 1초 원본은 늘리지 않고 사용합니다.
- 긴 영상은 간격별로 훑은 뒤 후보 구간을 자세히 확인합니다. 샘플 사이의 짧은 행동은 빠질 수 있습니다.
- 실제 촬영시각이 확인된 경우 시간 자막을 사용합니다. 모르는 시각을 임의로 만들지 않습니다.
- 기본 자막은 Pretendard SemiBold, 1080×1920 기준 시간 54px·문장 52px, 흰색 글씨와 검은 테두리입니다.
- 1080×1920, 24fps, H.264 MP4 출력. 현재 기본 렌더 범위는 4~20컷·총 10~40초이며 이보다 짧은 구성은 범위 조정이 필요합니다. 길이를 맞추려고 장면을 반복하지 않습니다.
- 사용 범위가 확인된 별도 음악 파일을 넣을 수 있습니다. 없으면 무음 시안으로 제작하며 음악 자동 검색 기능은 없습니다.

## 지원 환경과 검증 범위

| 환경 | 상태 |
| --- | --- |
| macOS 14 이상 · Apple Silicon | 같은 Mac의 빈 전용 캐시에서 v008 ZIP 설치·분석·10초 렌더 검증 |
| Intel Mac | 코드 경로 제공, 실제 장치 검증 전 |
| Windows 10/11 x64 | 시험판, 실제 Windows 설치·렌더 검증 전 |
| Windows ARM/32비트 · Linux | 미지원 |
| 아이폰·아이패드 단독 실행 | 미지원. 편집할 Mac/PC 필요 |

현재 기본 편집 입력은 **무음 H.264 SDR MP4**입니다. 휴대폰 영상의 HEVC/HDR·회전 정보·원음이 있으면 먼저 확인하고 처리 방법을 정합니다. 임의로 소리를 제거하거나 원본을 덮어쓰지 않습니다. 모든 휴대폰 형식을 바로 편집할 수 있다는 뜻은 아닙니다.

같은 Mac에서 격리 설치한 시험은 새 컴퓨터·새 운영체제나 실제 초보자 사용 시험을 대신하지 않습니다. 다운로드 보안 경고·조직 정책이 나타나면 에이전트에게 알려주세요. 보안 기능을 끌 필요는 없습니다.

## 포함 파일

- `daily-vlog/SKILL.md`: 단계별 제작과 확인 절차
- `daily-vlog/scripts/`: 환경 준비·분석·편집 코드
- `daily-vlog/runtime/`: 고정한 모듈 버전과 다운로드 해시
- `daily-vlog/references/`: 편집 계획·기본 스타일·지원 범위
- `daily-vlog/assets/fonts/`: Pretendard 폰트와 SIL OFL 1.1 라이선스
- 루트의 설치기와 `시작하기.txt`

개인 영상, 완성 영상, 계정 인증 정보, 설치된 Python과 도구 캐시는 포함하지 않습니다. 예제 스톡 영상과 음악도 별도로 준비해야 합니다. 원본 영상과 개인 자료는 저장소 밖에 보관하세요.

폰트 저작권과 이용 조건은 [폰트 라이선스](daily-vlog/assets/fonts/LICENSE.txt)를 참고하세요. 이 폰트는 시스템에 설치하지 않고 파일로 사용합니다.
