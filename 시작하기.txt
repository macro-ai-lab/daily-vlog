일상 브이로그 — Mac / Windows x64 시험판

먼저: 파일을 읽고 실행할 수 있는 Codex가 설치되고 로그인돼 있어야 합니다.
일반 웹 채팅에 ZIP만 올리는 방식이나 휴대폰 단독 실행은 지원하지 않습니다.

가장 쉬운 시작
1. ZIP을 압축 해제합니다.
2. 압축 해제한 폴더를 Codex 채팅에 끌어 넣고 이렇게 말합니다.
   “이 폴더의 일상 브이로그 스킬을 설치하고 필요한 편집 도구도 준비해줘.”
3. 설치나 네트워크에 대한 앱의 승인 요청이 나타나면 내용을 보고 승인합니다.
4. 사용할 영상을 아래 두 방법 중 편한 방식으로 전달합니다.
   A. 영상 파일을 채팅 입력창에 직접 첨부합니다. 여러 파일을 함께 첨부해도 됩니다.
      “$daily-vlog로 첨부한 영상들로 브이로그 만들어줘. 먼저 분석하고 콘티부터 보여줘.”
   B. 영상이 모인 폴더를 채팅에 끌어 넣거나 폴더 경로를 알려줍니다.
      “$daily-vlog로 이 폴더의 영상들로 브이로그 만들어줘. 먼저 콘티부터 보여줘.”
   첨부한 원본에 접근할 수 있으면 따로 폴더를 만들 필요가 없습니다. 앱에서 영상 첨부를 제공하지 않거나 원본을 읽을 수 없을 때만 재첨부나 폴더 경로를 안내합니다.
   큰 영상은 채팅에 올리지 않고 편집 컴퓨터에 저장한 뒤 파일/폴더 경로를 알려주세요.
   아이폰에만 있다면 먼저 편집 컴퓨터로 옮겨야 합니다. 원격 Mac은 아이폰 사진첩을 자동으로 읽지 않습니다.
   긴 원본도 미리 자를 필요 없이 “이 영상에서 쓸 만한 구간을 골라 콘티부터 보여줘”라고 요청할 수 있습니다.
5. 에이전트가 영상을 분석하고 장면 순서·예상 길이·자막 초안을 콘티로 보여줍니다. 보고 “좋아” 또는 바꿀 점을 말합니다.
6. 콘티가 정해지면 자막과 영상 분위기 예시를 보고 원하는 스타일을 선택합니다. 잘 모르겠으면 “추천안으로 해줘”라고 말합니다.
7. 선택한 내용으로 만든 시안을 보고 “글씨 좀 키워줘”, “이 장면 줄여줘”처럼 수정합니다. 마음에 들면 최종본으로 확정합니다.

직접 시작하려면 Mac은 install.command, Windows는 install-windows.cmd를 실행합니다. Windows 설치·실행은 실제 Windows PC 검증이 남아 있는 시험판입니다.
맥의 다운로드 보안 경고가 뜨면 에이전트에게 알려주세요. 보안 기능을 끌 필요는 없습니다.
같은 이름의 수정본/다른 버전은 덮어쓰지 않습니다. Windows에서 도구 설치만 중단됐다면 같은 배포본의 설치기를 다시 실행해 이어갈 수 있습니다.

알아둘 점
- 첫 실행에는 인터넷과 다운로드 공간이 필요합니다. 관리자 비밀번호나 Homebrew는 요구하지 않습니다.
- Python·편집 모듈은 별도 전용 공간에 자동 설치합니다. 설치가 끝나면 재사용합니다.
- 대상은 macOS 14 이상 또는 Windows 10/11 x64입니다. Mac의 무음 H.264 SDR MP4로 시험했습니다. 소리가 있는 영상, HEVC/HDR·회전 정보가 있는 영상은 먼저 알려줍니다. 임의로 소리를 지우지 않습니다.
- 실제 Windows 장치의 최초 설치·영상 제작과 실제 초보자 사용 시험은 아직 미검증입니다. Windows ARM/32비트는 지원하지 않습니다.
- Windows는 PowerShell 5.1 이상과 맑은 고딕을 사용합니다. 설치기는 이번 프로세스의 스크립트 실행만 허용하고 시스템 보안 정책을 바꾸지 않습니다. 차단되면 에이전트에게 알려주세요.
- 자동 장면 선택은 에이전트가 영상을 확인해 수행합니다. 항상 한 번에 완성되거나 일정 시간 안에 끝난다고 보장하지 않습니다.
- 원본·기존 결과를 보존하고 새 결과와 수정할 편집 계획을 남깁니다.
- 음악은 사용 범위가 확인된 별도 파일이 있을 때만 넣습니다. 없으면 무음부터 만듭니다.
- 이 편집 도구의 별도 유료 API 키는 필요 없습니다. Codex 등 에이전트 이용 요금은 별개입니다.
- 실제 결과 MP4의 생성은 로컬입니다. 에이전트의 영상 프레임 분석까지 완전 오프라인이라는 뜻은 아닙니다.
