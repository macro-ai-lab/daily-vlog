쉬운 설치 — 환경은 에이전트가 확인합니다

1. 파일과 명령 실행을 지원하는 Codex 또는 Claude Code에서 작업할 프로젝트를 엽니다.
2. 아래 주소와 문장을 함께 보내세요. ZIP을 받았다면 압축 해제한 폴더를 대신 전달해도 됩니다.

https://github.com/macro-ai-lab/daily-vlog

README를 읽고 이 기능을 설치해줘. 내 실행 환경과 폴더 권한을 확인해서 맞는 방법으로 진행하고 기존 파일과 개인 지침은 보존해줘. 설치 후 실제 사용 가능한 도구까지 점검해줘.

설치 파일 선택은 에이전트가 맡고 일반 설치 경로에는 Python·Git 사전 설치가 필요 없습니다.
Windows 기본 HTTPS가 실패하면 기존 Python으로 재시도합니다. 기존 Python도 없으면 현재 자동 설치를 완료할 수 없습니다.
계정 이름만으로 선제 차단하지 않고 실제 파일 작업 결과를 확인하며, 인증서·해시 검증은 유지합니다.
사용자가 별도 CMD를 직접 실행한 것을 에이전트 자동 설치 성공으로 기록하지 않습니다.
프로젝트에 설치했다면 이후에도 그 프로젝트에서 사용합니다.
실행 오류가 나면 README와 INSTALLATION.md를 읽고 처음 실패한 단계를 확인하도록 요청하세요.
파일 설치 성공과 실제 도구 사용 가능 여부는 다릅니다. 무조건 재설치·재시작하지 않습니다.
휴대폰/태블릿 단독 영상 편집은 지원하지 않습니다. 컴퓨터에서 진행하세요.
로그인·서비스 이용 요금은 별개이며, 설치만으로 컴퓨터 유즈 권한이 추가되지 않습니다.
